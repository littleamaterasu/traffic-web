<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> lib | `domain` and `apiKey` arrive as arguments; domain must already be `normalizeDomain` output |
| lib -> TabAPI | outbound HTTPS to a fixed base URL with Bearer secret |
| TabAPI -> lib | response body contains text and URLs authored by arbitrary third-party websites (untrusted) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | apiKey handling in referring-sites.ts | mitigate | Key used only in the Authorization header; never in URL, cache key, error message, result or fixtures; tests assert messages and serialized results do not contain `test-key-123` |
| T-02-02 | Tampering | outbound URL construction | mitigate | Fixed `TABAPI_BASE_URL`; domain placed only via `encodeURIComponent` as one path segment; `redirect: "error"`; test with `a.com/../x` |
| T-02-03 | Tampering / XSS | title, anchor, from_url, to_url from third-party pages | mitigate | Field whitelist built explicitly; capString (200/120), safeHttpUrl http/https only with no credentials and length cap, items with unsafe from_url dropped, unsafe to_url nulled, numbers clamped; unknown fields dropped |
| T-02-04 | Denial of Service | oversized upstream body | mitigate | 1,000,000-byte cap enforced on content-length and while streaming; 30s timeout; at most 20 items kept |
| T-02-05 | Denial of Service / cost | credit burn (5 credits per call) | mitigate | 24h cache + in-flight dedup via createCachedStore; failures never cached (TabAPI does not charge errors); empty results cached 10 min only to avoid repeat charges without hiding new data for long |
| T-02-06 | Information Disclosure | upstream error body | mitigate | Upstream error body discarded; only status-derived Vietnamese messages returned |
| T-02-SC | Tampering | package installs | accept | No new dependencies in this plan |
</threat_model>
