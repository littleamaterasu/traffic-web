## Phase 2 Panel Contract

**Placement (D-05):** full-width `Panel` inserted immediately after the two-column grid containing "Lượt truy cập theo tháng" + "Nguồn traffic", before the "Quốc gia hàng đầu"/"Từ khóa hàng đầu" grid. Rationale: the 4-column table with long anchor text needs full width (AI-referrals panel precedent); Phase 4 owns the canonical report order later.

**Fetch trigger (D-01):** the panel auto-fetches `GET /api/referring-sites?domain={domain}` on mount — no user action. Mount it inside `Results` with `key={data.domain}` (same remount pattern as `AdsPanel`) so a new search refetches. The traffic report renders without waiting for this panel.

**Loading state (in-panel):** while in flight, render the global loading pattern inside the panel body: `role="status"` wrapper with `<div className="loading-stripes h-5 border-2 border-[#171710]" />` + `<p className="mt-3 text-center font-black uppercase">Đang tải backlink…</p>`. 20s `AbortController` timeout, matching the main-search pattern; abort renders the error state below.

**Error state (in-panel):** non-OK / network failure renders the server message (`ApiErrorBody.error.message`) in an in-panel block: `<p role="alert" className="border-2 border-[#171710] bg-[#ffb3c7] px-3 py-2 text-sm font-black">{message}</p>`. The rest of the report is unaffected (SC3; full per-section isolation with retry is Phase 4 / RPT-04).

**Honesty labeling (D-07 / REFS-03):** constant panel badge `Backlink — không phải lượt truy cập` + the `PANEL_INFO.referringSites` "i" entry whose summary explicitly distinguishes link-based referring domains from the visit-weighted "Giới thiệu" row in Nguồn traffic.

**Table (D-06 / REFS-01, REFS-02):** top 10 rows, rendered in API-provided rank order — never re-sorted client-side. Columns:

| Column | Header (Vietnamese) | Cell classes | Null render |
|--------|--------------------|--------------|-------------|
| Referring domain | `Tên miền` | `px-5 py-4 font-black break-all` | never null (row key) |
| Domain rating | `DR (0–100)` | `px-5 py-4 text-right font-mono font-bold`, integer | `—` |
| Backlink count | `Số backlink` | `px-5 py-4 text-right font-mono font-bold`, `formatNumber` | `—` |
| Anchor / link context | `Anchor / ngữ cảnh` | `px-5 py-4 font-bold break-words` + `data-stack="true"` | `—` |

**Probe gate (D-03):** column set assumes the API provides DR, backlink count, and anchor/link context. The live TabAPI probe during planning locks the real field mapping in RESEARCH.md; if a field does not exist, drop that column and update `PANEL_INFO.referringSites.metrics` to match — never render an invented column. No pagination or "load more" (REFS-07 is v2). Referring domains render as plain text — no external links in this phase.

## Spacing Scale

Declared values (Tailwind default 4px base; all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `py-1`) | Inline icon gaps, badge vertical padding |
| sm | 8px (`gap-2`, `px-2`) | Badge padding (`px-2 py-1`), compact element spacing |
| md | 12px (`gap-3`) | Intra-panel element spacing |
| lg | 16px (`gap-4`, `p-4`) | Card padding, metric grid gaps |
| xl | 20px (`p-5`, `px-5`) | Panel content padding, table cell padding |
| 2xl | 24px (`p-6`) | Mobile stacked-row padding, modal padding |
| 3xl | 32px (`gap-8`, `space-y-8`) | Between-panel rhythm (established) |

Exceptions: none new. Established micro-padding of 2px/6px (`px-1.5 py-0.5`) exists only in pre-existing badge styles — the new panel uses the ≥4px scale above. Larger steps (48/64px) are unused in the existing UI and not introduced here.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Panel heading | 18 → 20px (`text-lg sm:text-xl`), uppercase | 900 (`font-black`) | 1.25 |
| Body / input | 16px (`text-base`) | 700 (`font-bold`) | 1.5 |
| Table cell / dense text | 14px (`text-sm`) | 700 (`font-bold`) | 1.5 |
| Label / badge / table head | 12px (`text-xs`), uppercase | 900 (`font-black`) | 1.35 |

Weights: exactly two — 700 for data/body cells, 900 for headings, labels, badges, and numeric emphasis. Numeric table cells additionally use `font-mono`. Explanatory paragraphs (PANEL_INFO modal) use `leading-relaxed` (1.625), inherited from the primitive. Out-of-scope exception: the hero display type (`text-5xl`–`text-8xl`) in the untouched header.

| partial | table cells | ✅ covered | Any null DR / backlink count / anchor renders "—" — never 0, never a dropped row (RPT-03 precedent) |
