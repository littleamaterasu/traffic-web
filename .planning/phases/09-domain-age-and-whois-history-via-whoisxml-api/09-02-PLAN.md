<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> WhoisXML | apiKey is a URL query parameter on both upstream hosts |
| WhoisXML response -> compact result | Upstream bodies carry raw WHOIS text and personal contacts |
| caller domain -> upstream request | Domain string is already normalized by `normalizeDomain` in routes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06 | Information Disclosure | requestWhois URL / errors | mitigate | URL never logged or echoed; error messages are fixed Vietnamese strings; tests assert key absent from errors, results, and cache keys (keys are domain only) |
| T-09-07 | Tampering | upstream URL construction | mitigate | Only the two fixed base-URL constants plus URLSearchParams; domain only in a param value, never in host/path |
| T-09-08 | Information Disclosure | history records | mitigate | toHistoryInput whitelists 5 fields; rawText, cleanText, contacts, emails, phones are dropped server-side; test uses sentinel strings |
| T-09-09 | Denial of Service / cost | history purchase | mitigate | Preview first, HISTORY_RECORD_CAP = 100 refuses over-cap purchases, preview and compact result cached 24h with in-flight dedup |
| T-09-10 | Repudiation/Spoofing | upstream error bodies | mitigate | Upstream body text is never copied into messages; unknown statuses collapse to 502 whois_error |
| T-09-11 | Elevation | Dependencies | accept | No new packages; native fetch only |
</threat_model>
