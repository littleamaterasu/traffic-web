| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-09-18 | Information Disclosure | WHOIS_API_KEY | mitigate | Read only server-side after validation; missing -> fixed Vietnamese message; tests assert key absent from every response body and error text |
| T-09-19 | Information Disclosure | error messages | mitigate | Only WhoisApiError messages (fixed Vietnamese strings) pass through; any other thrown error is replaced by a generic message |
| T-09-20 | Information Disclosure | raw WHOIS / contacts | mitigate | Route returns lib's compact types only; sentinel test proves rawText and emails are absent |
| T-09-21 | Denial of Service / cost | history route | mitigate | Preview-first, 100-record cap, 24h cache, in-flight dedup; second request makes zero upstream calls |
