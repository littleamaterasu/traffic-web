| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering/SSRF | fetchTrustpilotProfile | mitigate | Base URL accepted only as a parameter sourced from server env; parsed, http/https only, only `origin` used, path fixed to /api/reviews, redirect:"error", body limits fixed constants |
| T-10-02 | Tampering/XSS | normalizeTrustpilotBody | mitigate | Field-by-field whitelist, string trim + length caps, URL scheme allow-list, number clamping; no HTML passthrough, unknown fields dropped |
| T-10-03 | Information Disclosure | TrustpilotApiError messages | mitigate | Fixed Vietnamese messages; never include base URL, upstream body or status text |
| T-10-04 | Denial of Service | slow ~21s upstream / huge body | mitigate | AbortSignal.timeout(45s), 1,000,000-char response cap, 24h cache + in-flight dedup via createCachedStore |
| T-10-05 | Information Disclosure | review text persistence | mitigate | In-memory Map cache only, no DB/files/logging |
